02 / HOW IT WORKS

A setup guide that speaks human.

No mystery settings. Pick one area, pick one time, provide the official export, and let the compare logic do the quiet work.

01

Choose one area

Use a city, county, ZIP, or neighborhood address with a radius. The Boynton Beach file is only an example, not a default.

02

Save a baseline

The first successful list becomes yesterday's reference. It sends no full-list alert.

03

Check daily

Today's list is compared by FDLE person number. Only IDs missing from yesterday are reported.

04

Recover after resets

A second timer verifies the daily timer and recreates it from the same settings file when needed.
